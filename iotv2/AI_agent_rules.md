# Правила для AI-агента по формированию инструкций по охране труда

## Организация
- Название организации: **ООО "Слайс ЛТД"**

## Структура и содержание инструкций

### Обязательная последовательность разделов (Приказ Минтруда РФ от 29.10.2021 N 772Н, раздел III)

Инструкции должны содержать следующие разделы в указанном порядке:

1. **Общие требования охраны труда**
2. **Требования охраны труда перед началом работы**
3. **Требования охраны труда во время работы**
4. **Требования охраны труда в аварийных ситуациях**
5. **Требования охраны труда по окончании работы**

### Правила разработки

- ✓ Использовать последовательность и пункты изложенные в Приказе Минтруда РФ от 29.10.2021 N 772Н
- ✓ Возможно расширять пункты из приказа
- ✗ Урезать пункты запрещено (за исключением случаев когда этого требует специфика должности)
- ✓ Перечень СИЗ и ссылка на карту оценки производственных рисков выносить в приложение №1
- ✓ В п. 1.5.1 инструкции ставить ссылку на Приложение №1 с указанием: "Перечень средств индивидуальной защиты для [должность] приведен в Приложении №1"
- ✓ В Приложении №1 оставлять структурированные заглушки для заполнения результатами СОУТ и ОПР (таблицы с пояснениями, что заполнять)
- ✓ Использовать для анализа трудовой функции существующие инструкции из других папок
- ✓ Форматирование: готово для вставки в Word с нумерацией пунктов и разделов
- ✓ Язык: русский

### Выходные данные

- Формат: .md (Markdown)
- Структура: полная нумерация разделов и пунктов
- Приложения: отдельный раздел приложений в конце

## Ведение рабочего журнала

- Вести файл **workbook.md** в папке iotv2
- Записывать туда новые требования и изменения, возникающие в процессе формирования инструкций
- Отмечать источники и ссылки на существующие инструкции
