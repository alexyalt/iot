# Шаблон структуры инструкции по охране труда

## Использование этого шаблона

Этот документ описывает структуру, которую должны соблюдать новые инструкции по охране труда для ИОТ.

---

## Формат имени файла

```
ИОТ-[КАТЕГОРИЯ]-[НОМЕР].docx
```

**Примеры:**
- `ИОТ-ОПР-01.docx` - Оператор, инструкция 1
- `ИОТ-МНТ-03.docx` - Монтажник, инструкция 3
- `ИОТ-ЭЛК-02.docx` - Электрик, инструкция 2

### Кодирование категорий

После определения должностей в `user_polls/positions_and_tools_questionnaire.md` используйте сокращения:

| Кодология | Должность/Область | Макс файлов |
|-----------|------------------|------------|
| ВИД | Видеонаблюдение | 16 |
| СПС | Система спасения | 12 |
| ФУНК | Функционал | 2 |
| [NEW] | [Новые] | [?] |

## Основная структура документа

### 1. Заголовок (без нумерации)

```
[Пусто - несколько строк для центрирования]
ООО «СЛАЙС ЛТД»

ИНСТРУКЦИЯ
по охране труда

[ОПИСАНИЕ РАБОТЫ/ДОЛЖНОСТИ]

ИОТ-[КАТЕГОРИЯ]-[ХХ]

Сведения о документе
```

**Примеры описаний:**
- "При работе с мультиметром (общая)"
- "При монтаже устройств IoT"
- "При техническом обслуживании сенсорных систем"
- "При работе с инструментом и приспособлениями (общая)"

### 2. Содержание инструкции

#### 1. ОБЩИЕ ТРЕБОВАНИЯ ОХРАНЫ ТРУДА

**Типовое содержание:**

- 1.1. Общие положения и область применения
- 1.2. Основание для разработки (ссылки на законы и нормативы)
- 1.3. Обязательность соблюдения требований
- 1.4. Требования к работникам перед началом работы:
  - Медицинский осмотр
  - Вводный инструктаж
  - Первичный инструктаж на рабочем месте
  - Обучение по охране труда
  - Первая помощь
  - Средства индивидуальной защиты (СИЗ)
  - Пожарная безопасность
  - Стажировка на рабочем месте

- 1.5. Опасности и вредные факторы
  - Электрический ток
  - Электромагнитное излучение
  - Статическое электричество
  - Механические травмы
  - Температурные воздействия
  - Другие (в зависимости от характера работ)

- 1.6. Средства индивидуальной защиты:
  - Перечень обязательных СИЗ
  - Условия использования
  - Требования к качеству

- 1.7. Санитарные требования

#### 2. ТРЕБОВАНИЯ ОХРАНЫ ТРУДА ПЕРЕД НАЧАЛОМ РАБОТЫ

**Типовое содержание:**

- 2.1. Проверка рабочего места
- 2.2. Проверка оборудования и инструментов
- 2.3. Проверка средств индивидуальной защиты
- 2.4. Проверка состояния здоровья (субъективная оценка)
- 2.5. Надевание СИЗ в правильной последовательности
- 2.6. Проверка соответствия рабочего места нормам

#### 3. ТРЕБОВАНИЯ ОХРАНЫ ТРУДА ВО ВРЕМЯ РАБОТЫ

**Типовое содержание:**

- 3.1. Безопасные методы и приёмы работы
  - Техника безопасности
  - Последовательность операций
  - Ограничения и запреты
  
- 3.2. Требования к выполнению операций (детально для каждой типовой операции)
  - Обращение с инструментом
  - Работа с оборудованием
  - Обращение с материалами
  
- 3.3. Правила использования оборудования и инструментов

- 3.4. Использование средств индивидуальной защиты

- 3.5. Поддержание порядка на рабочем месте

- 3.6. Требования при работе в неблагоприятных условиях
  - На высоте
  - В закрытых пространствах
  - В условиях повышенной влажности
  - В условиях низких/высоких температур

#### 4. ТРЕБОВАНИЯ ОХРАНЫ ТРУДА ПО ОКОНЧАНИИ РАБОТЫ

**Типовое содержание:**

- 4.1. Выключение и отключение оборудования
- 4.2. Проверка отсутствия опасности
- 4.3. Сборка и хранение оборудования
- 4.4. Очистка рабочего места
- 4.5. Возвращение инструмента и СИЗ на место хранения
- 4.6. Докладывание руководителю об окончании работы
- 4.7. Осмотр рук и лица на предмет повреждений

#### 5. ТРЕБОВАНИЯ ОХРАНЫ ТРУДА В АВАРИЙНЫХ СИТУАЦИЯХ

**Типовое содержание:**

- 5.1. Действия при поражении электрическим током
- 5.2. Действия при ожогах
- 5.3. Действия при механических травмах
- 5.4. Действия при загорании
- 5.5. Действия при появлении странных звуков/запахов
- 5.6. Действия при отказе оборудования
- 5.7. Эвакуация при ЧС
- 5.8. Первая помощь при ДТП (если применимо)
- 5.9. Оповещение руководства и служб спасения

### 6. ПРИЛОЖЕНИЕ (вспомогательная информация)

**Типовое содержание:**

- Приложение A: Электробезопасность (термины, напряжения)
- Приложение B: СИЗ и их применение
- Приложение C: Справочная информация об оборудовании
- Приложение D: Допускаемые рабочие зоны и ограничения
- Приложение E: Контакты служб экстренной помощи
- Приложение F: Чеклист проверки перед началом работы

### 7. Служебные таблицы (в конце документа)

**Таблица согласования:**
```
СОГЛАСОВАНО                              УТВЕРЖДАЮ
Должность: _______                       Должность: _________
ФИО: _______                             ФИО: _________
Подпись: _______                         Подпись: _________
Дата: _______                            Дата: _________
```

## Система ссылок и кодов

В текстах используется система перекрёстных ссылок:

```
[{[КОД-ХХ]}] Текст требования
```

**Примеры кодирования:**
- `[{[ОБЩ-01]}]` - Общие требования, пункт 1
- `[{[ОБСЛУЖ-02]}]` - Обслуживание, пункт 2
- `[{[ПРЕДОСОР-03]}]` - Предостережение о собрании предметов, пункт 3

## Стиль оформления

### Основные стили текста

| Элемент | Стиль | Применение |
|---------|-------|-----------|
| Заголовки разделов | Heading 1 | "1. ОБЩИЕ ТРЕБОВАНИЯ..." |
| Подзаголовки | Normal (с отступом) | "1.1. Общие положения..." |
| Текст требований | Normal | Основной текст требований |
| Списки (маркированные) | List Bullet | "- Требование 1..." |
| Списки (нумерованные) | List Number | "1) Требование 1..." |
| Таблицы | Table Grid | Служебные таблицы |

### Цветовое выделение

- **Чёрный текст** - стандартный текст требований
- **Никаких цветов** - не рекомендуется использовать
- Акценты - используйте **жирный** или _курсив_ где необходимо

### Предупреждающие блоки

Используйте текстовые блоки для предупреждений:

```
ВНИМАНИЕ! 
Высокое напряжение опасно для жизни!
```

```
ОСТОРОЖНО!
Используйте средства индивидуальной защиты при работе с агрессивными средами.
```

## Примеры разных типов инструкций

### Тип A: Инструкция по должности (общая)

**Пример:** ИОТ-ОПР-01 - "При выполнении обязанностей оператора (общая)"

- Содержит требования для работника на типовой должности
- Охватывает все аспекты работы
- Ссылается на специальные инструкции по операциям

### Тип B: Инструкция по инструменту/оборудованию

**Пример:** ИОТ-МНТ-02 - "При работе с паяльником и припоем"

- Сфокусирована на конкретном инструменте
- Описывает все аспекты его использования
- Включает специфичные опасности этого инструмента

### Тип C: Инструкция по операции/процессу

**Пример:** ИОТ-ЭЛК-03 - "При монтаже электрических соединений (380В)"

- Сфокусирована на конкретной операции
- Включает пошаговую процедуру
- Описывает специфичные риски этой операции

### Тип D: Инструкция по условиям работы

**Пример:** ИОТ-[КОД]-04 - "При работе на высоте свыше 3 метров"

- Сфокусирована на условиях окружающей среды
- Описывает спецсредства и требования
- Включает действия при возникновении опасностей
