# Дополнительные инструкции по охране труда

В `printable/` подготовлены 23 DOCX-проекта в формате образца СПС-10: 20 должностных и 3 по видам работ. Вопросы для согласования и предварительные коды выделены жёлтым. Перечень недоработок и границы охвата: `НЕДОРАБОТКИ.md` и `printable/НЕДОРАБОТКИ.docx`. Генератор: `workbook/tools/build_additional.py`. Исходные материалы и предыдущие черновики сохранены в `workbook/` и `user_polls/`. Согласованные СПС-01–12 не менялись; АХО отложено.
