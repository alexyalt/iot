# Дополнительные инструкции

## Обзор

Эта папка содержит новые инструкции по охране труда, разработанные на основе опросника `user_polls/positions_and_tools_questionnaire.md`.

## Структура папки

```
additional_instr/
├── README.md (этот файл)
├── TEMPLATE_STRUCTURE.md (описание стандартной структуры)
├── [КАТЕГОРИЯ]_инструкции/
│   ├── ИОТ-[КОД]-01.docx
│   ├── ИОТ-[КОД]-02.docx
│   └── ...
└── tools_and_operations/
    ├── инструкции_по_инструментам.md
    ├── инструкции_по_операциям.md
    └── ...
```

## Статус разработки

### ⏳ Ожидание информации

Перед началом разработки инструкций требуется заполнить опросник:

📋 **Файл:** `user_polls/positions_and_tools_questionnaire.md`

Необходимо предоставить информацию по:
1. Должностям/ролям для инструкций
2. Сокращениям кодов
3. Инструментам и оборудованию
4. Специфичным операциям и условиям

### 📅 Этапы разработки (после получения информации)

1. **Этап 1:** Создание инструкций для должностей
   - Одна инструкция на должность (общая)
   - Можно несколько специализированных

2. **Этап 2:** Инструкции по инструментам
   - Для каждого специального инструмента
   - Для каждого оборудования

3. **Этап 3:** Инструкции по операциям
   - Для сложных или опасных операций
   - Для операций в специфичных условиях

4. **Этап 4:** Интеграция
   - Проверка соответствия стандартам
   - Согласование с руководством
   - Загрузка в основной репозиторий

## Правила разработки

### Формат и стиль

- **Язык:** Русский
- **Формат документов:** .docx (Word)
- **Структура:** Согласно `TEMPLATE_STRUCTURE.md`
- **Стандарты:** ГОСТ, СанПиН, ТК РФ

### Именование файлов

```
ИОТ-[КАТЕГОРИЯ]-[НОМЕР].docx
```

**Правила:**
- [КАТЕГОРИЯ] — 4 буквы сокращение должности/области
- [НОМЕР] — 2 цифры (01, 02, ..., 99)
- Пример: `ИОТ-ОПР-01.docx`

### Содержание

Каждая инструкция должна включать:

1. ✅ Общие требования охраны труда (опасности, требования, СИЗ)
2. ✅ Требования перед началом работы (проверки)
3. ✅ Требования во время работы (процедуры)
4. ✅ Требования по окончании работы (завершение)
5. ✅ Требования в аварийных ситуациях (ЧС)
6. ✅ Приложения (справочная информация)
7. ✅ Служебные таблицы (согласование/утверждение)
