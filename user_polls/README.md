# Анализ существующих инструкций

## Обзор проекта

**Организация:** ООО «СЛАЙС ЛТД»
**Предмет:** Инструкции по охране труда для работы с ИОТ (Интернет вещей)

### Текущие категории инструкций

#### 1. ВИД-ХХ (Видеонаблюдение/Инспекция)
- **Количество:** 16 файлов (ВИД-01 до ВИД-16)
- **Область:** Видеонаблюдение и инспекционные работы
- **Типичное содержимое:** 
  - Общие требования охраны труда
  - Требования перед началом работы
  - Требования во время работы
  - Требования по окончании работы
  - Требования в аварийных ситуациях

#### 2. СПС-ХХ (Система спасения/безопасности)
- **Количество:** 12 файлов (СПС-01 до СПС-12)
- **Область:** Системы спасения и безопасности
- **Статус:** Более объёмные файлы (55-59 КБ в среднем)

#### 3. ФУНК-ХХ (Функционал)
- **Количество:** 2 файла (ФУНК-01, ФУНК-02)
- **Область:** Функциональные аспекты
- **Размер:** ~50 КБ каждый

### Структура документа (примерный шаблон)

Каждый файл .docx содержит:

1. **Заголовок документа**
   - ООО «СЛАЙС ЛТД»
   - ИНСТРУКЦИЯ по охране труда
   - По работе с инструментом и приспособлениями (общая)
   - Номер и наименование: ИОТ-[КОД]-[ХХ]

2. **Сведения о документе**
   - Информационная справка
   - Дата разработки и утверждения

3. **Основные разделы**
   - 1. ОБЩИЕ ТРЕБОВАНИЯ ОХРАНЫ ТРУДА
   - 2. ТРЕБОВАНИЯ ОХРАНЫ ТРУДА ПЕРЕД НАЧАЛОМ РАБОТЫ
   - 3. ТРЕБОВАНИЯ ОХРАНЫ ТРУДА ВО ВРЕМЯ РАБОТЫ
   - 4. ТРЕБОВАНИЯ ОХРАНЫ ТРУДА ПО ОКОНЧАНИИ РАБОТЫ
   - 5. ТРЕБОВАНИЯ ОХРАНЫ ТРУДА В АВАРИЙНЫХ СИТУАЦИЯХ
   - 6. ПРИЛОЖЕНИЕ (вспомогательная информация)

4. **Служебные таблицы**
   - Согласовано (подпись, должность)
   - Утверждаю (подпись, должность)

### Коды ссылок в текстах

Инструкции используют коды в формате `[{[КОД]}]` для перекрёстных ссылок:
- `[{[ОБЩ-01]}]` - Общие требования, пункт 1
- `[{[ОБСЛУЖ-02]}]` - Обслуживание, пункт 2
- И т.д.

## Рекомендации для создания новых инструкций

### При разработке новых должностей/категорий

1. **Следовать существующей структуре и формату**
   - Использовать те же стили Word
   - Сохранять порядок разделов
   - Применять аналогичную систему нумерации

2. **Использовать принятую систему кодирования**
   - 4 буквы для категории: `ИОТ-[КОД]-ХХ`
   - Нумерация от 01 до ХХ (в зависимости от количества)
   - Пример: `ИОТ-ОПР-01`, `ИОТ-МНТ-03`

3. **Соблюдать консистентность**
   - Одинаковые разделы для всех должностей
   - Единый стиль оформления
   - Согласованная терминология

4. **Учитывать специфику ИОТ**
   - Электробезопасность (напряжения, токи)
   - Работа с сенсорами и микроконтроллерами
   - Программное обеспечение и интеграция
   - Беспроводные технологии (ЭМ излучение)

## Требуемая информация для продолжения

Для создания качественных инструкций требуется:

1. **Перечень должностей** - кто будет использовать эти инструкции
2. **Сокращения кодов** - как их обозначать в названиях файлов
3. **Список инструментов и оборудования** - что конкретно используется
4. **Специфичные операции** - особенности работы на вашем предприятии
5. **Дополнительные разделы** - если требуются отличия от текущей структуры
