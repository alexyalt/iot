# Реестр должностей и план инструкций

**Коды по ответу пользователя:** указывать серии КЛИ/ТРА/ЭКС/СНА/АДМ для должностей и продолжать серию ВИД для операций. Предлагаемая нумерация ниже последовательна; при DOCX-сборке сверить её с реестром, не менять без необходимости.
**АХО:** исключено из текущего этапа по указанию пользователя.
**Садово-парковая служба:** согласованные должностные инструкции не менять; исправления пользователя по ошибочным позициям и новому дворнику отражены ниже. `ИОТ-СПС-12` оставить без изменений.

- «Старший садовник» и «временный сотрудник» указаны ошибочно — исключить эти позиции из нового перечня, новые инструкции не создавать.
