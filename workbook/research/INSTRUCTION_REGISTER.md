# Реестр должностей и план инструкций

**Статус кодов:** временные рабочие ярлыки; официальный код не назначать до сверки реестра работодателя и непрерывности нумерации.  
**АХО:** исключено из текущего этапа по указанию пользователя.  
**Садово-парковая служба:** имеющиеся должностные инструкции в основном уже охвачены СПС; проверять необходимость нового документа только при выявлении непокрытой должности/функции.

## 2. Отдельные инструкции по видам работ/оборудованию — план предварительный

Эти документы не заменяют должностные инструкции. Финальный состав определяется после сверки области применения существующих ВИД/ФУНК с оборудованием и операциями компании.

| Кандидат на отдельную инструкцию | Подтверждение из ответов | Решение/проверка |
|---|---|---|
| Работа с чистящими/дезинфицирующими средствами | Подтверждены все типы из анкеты: щелочные, кислотные, дезинфектанты, абразивные порошки, концентраты для разведения, аэрозоли | Разработать отдельный рабочий черновик; получить наименования/паспорта безопасности/порядок дозирования до финализации |
| Работа с роторным полотёром и машиной для влажной уборки пола | Оборудование прямо перечислено пользователем | Проверить модели, питание, руководство изготовителя, наличие существующей применимой инструкции |
| Работа с пылесосами (сетевыми и аккумуляторными) | Оборудование прямо перечислено пользователем | Проверить, покрывается ли общий ВИД-02/03; отдельный документ делать только если общая инструкция не покрывает фактические риски |
| Работа с мойкой высокого давления 220 В | Оборудование и напряжение прямо указаны пользователем; вода + электропитание требуют отдельной проверки рисков | Рассмотреть самостоятельную инструкцию; запросить модель/руководство, место/поверхности мойки, условия электропитания и СИЗ |
| Уборка санитарных комнат | Вид помещения прямо указан; ответ не подтверждает медицинские помещения/биологические отходы | Включить конкретные операции в должностную КЛИ-инструкцию; отдельную инструкцию назначать только при особом режиме/отходах/дезинфекции |
| Погрузочно-разгрузочные работы | Для подсобного рабочего прямо указана помощь; уже есть ВИД-09 | Не дублировать до проверки применимости и перекрёстных ссылок |
| Работа на высоте с лестниц/стремянок | Для подсобного рабочего прямо указана; уже есть ВИД-12 | Не дублировать до сверки применимости; уточнить высоты/допуски/виды лестниц |

## 3. Предварительный объём

- Должностные инструкции: **19 отдельных документов** — целевое покрытие, не считая АХО и уже охваченных должностей САД.
- Документы по видам работ/оборудованию: число пока **не фиксируется**. Есть 3–4 самостоятельных кандидата по клинингу, плюс возможные документы по операциям после сверки действующих ВИД/ФУНК.
- Никакой документ пока не имеет статуса «готов к печати». Все черновики должны пройти содержательную проверку, уточнение открытых данных и DOCX-верстку по соответствующему классу образца.
