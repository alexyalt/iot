## 🧹 СЛУЖБА КЛИНИНГА (КЛИ)

### Ответ 1.1: Какие основные типы чистящих средств используются?

```
Щелочные растворы, кислотные растворы, дезинфектанты, 
абразивные порошки, концентраты (требующие разведения), 
распыляемые аэрозоли
```

**Применение:** КЛИ-01, КЛИ-02, КЛИ-05 (операция по химикатам)

---

### Ответ 1.2: Используется ли электрооборудование при уборке?

```
Да: пылесосы (сухие), моющие пылесосы, полотеры/шлифовальные 
машины, воздуходувы, машины для влажной уборки полов
```

**Применение:** КЛИ-01, КЛИ-04, КЛИ-06 (операция по электроинструменту)

---

### Ответ 1.3: Специфичные помещения

```
Санитарные комнаты (риск биологического заражения), 
производственные помещения, кухни (жир, горячие поверхности), 
медицинские кабинеты (инфекционный риск)
```

**Применение:** КЛИ-01 (адаптация под помещения)

---

### Ответ 1.4: Физическая нагрузка

```
Поднятие тяжестей (вес, частота), положение тела (стоя, наклоны, 
коленопреклоненное), монотонные движения, смены 
(продолжительность, количество в день)
```

**Применение:** КЛИ-01, КЛИ-02 (раздел физической нагрузки)

## 🚗 СЛУЖБА ТРАНСПОРТА (ТРА)

```

грузовики (каб-над-двигателем), специальный транспорт 
(поливочные, подметальные)
```

**Применение:** ТРА-01 (адаптация под разные типы)

Управление: организация, безопасность

### Ответ 3.4: Пассажиры
