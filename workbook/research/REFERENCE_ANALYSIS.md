# Разбор согласованных образцов инструкций

**Основание:** DOCX из `Инструкции_ОТ/` в ветке `feature/additional-instructions` (30 файлов).
**Назначение:** фиксирует, какие образцы использовать для должностных инструкций и какие — для инструкций по видам работ. Это основной принцип дальнейшей разработки в `workbook`.

## 1. Вывод по типам документов

### А. Инструкции по должности — образец СПС

В наборе есть полноценные инструкции для должностей Садово-парковой службы (СПС). Примеры:

- `ИОТ-СПС-01.docx` — начальник садово-парковой службы;
- `ИОТ-СПС-02.docx` — главный садовник;
- `ИОТ-СПС-03.docx` — ведущий садовник;
- `ИОТ-СПС-04.docx` — садовник;
- `ИОТ-СПС-05.docx` — младший садовник;
- `ИОТ-СПС-06.docx` — агроном;
- `ИОТ-СПС-08.docx` — ведущий инженер садово-паркового хозяйства;
- `ИОТ-СПС-09.docx` — оператор по поливу;
- `ИОТ-СПС-10.docx` — уборщик территории;
- `ИОТ-СПС-11.docx` — рабочий по благоустройству территории;
- `ИОТ-СПС-12.docx` — техник по эксплуатации и ремонту оборудования (оставить как есть по прямому указанию пользователя). В ответе `1d009de` пользователь исключил ошибочные строки «старший садовник» и «временный сотрудник», а «уборщик территорий (разнорабочий)» уточнил как дворника; для дворника подготовлен отдельный проект ИОТ-СПС-13 на основе СПС-10.

В должностном образце название и область действия относятся к конкретной должности: например, в пунктах 1.1 и 1.3 прямо назван уборщик территории либо руководитель службы. Поэтому должностные документы КЛИ/ТРА/ЭКС/СНА/АДМ нельзя строить как универсальную инструкцию ВИД и ограничивать заменой названия.

**Основной образец для будущих должностных документов:** выбрать близкую по функции СПС-инструкцию для сравнения содержания и верстки. Для уборщика помещений наиболее близок СПС-10 (уборщик территории), но его текст нельзя копировать как содержание: наружная уборка и уборка помещений имеют разные рабочие операции и опасности.

### Б. Инструкции по видам работ/оборудованию — образцы ВИД и ФУНК

`ВИД` — это вид работы или применения инструмента/оборудования, а не должность. По названиям имеющихся документов:

- ВИД-01 — инструмент и приспособления (общая);
- ВИД-02/03 — аккумуляторный/сетевой электроинструмент;
- ВИД-09 — погрузочно-разгрузочные работы;
- ВИД-12 — работа на высоте с лестницами/стремянками;
- ВИД-13 — пестициды и агрохимикаты;
- другие ВИД — отдельные машины и инструменты.

`ФУНК` в имеющемся наборе также описывает специализированные рабочие операции/оборудование: машинное отделение подъёмника и рабочую люльку, а не общие требования для административной должности.

Такие документы следует использовать как источник отдельной инструкции на операцию/оборудование или как перекрёстный документ, если его область действительно охватывает операцию. Не создавать повторно инструкцию на работу на высоте или погрузочно-разгрузочные работы, пока не сверено, что существующие ВИД-12 и ВИД-09 применимы к условиям и работникам.

### В. Общий каркас и оформление

У рассмотренных образцов общий внешний формат: титульная часть ООО «СЛАЙС ЛТД», название, код, сведения о документе, 5 основных разделов, служебные таблицы. Порядок основных разделов образца:

1. Общие требования охраны труда;
2. Требования перед началом работы;
3. Требования во время работы;
4. Требования в аварийных ситуациях;
5. Требования по окончании работы.

В документах обычно есть 3 таблицы. При создании DOCX нужно сохранять исходный файл как основу для верстки/оформления, чтобы не потерять таблицы, поля и служебные элементы. Текстовые черновики `.md` нужны только для содержательной подготовки и рецензирования, они не являются готовыми инструкциями.

## 2. Принцип адаптации содержания

1. Для каждой должности отдельно установить область применения, реально поручаемые операции и ответственность по должностной инструкции/ответам пользователя.
2. Сформировать опасности из этих операций, а не из общего перечня «типовых» рисков.
3. Сопоставить опасности с локальной оценкой профессиональных рисков, СОУТ, инструкциями изготовителей и фактическими СИЗ. Если соответствующие документы/данные не предоставлены, отметить вопрос как открытый, а не выдавать предположение за проверенный факт.
4. Для отдельного вида работ использовать ВИД/ФУНК-подход. В должностной инструкции указать, что соответствующую работу выполняют только при наличии допуска/обучения и применяют профильную инструкцию, если это следует из фактической системы документов работодателя.
5. Ссылки и коды, нормативные ссылки, сроки обучения, медосмотры, СИЗ и параметры допуска проверять отдельно до DOCX-этапа. Не копировать правовые/организационные утверждения автоматически без проверки актуальности и применимости.
6. Перед финальным DOCX выполнить редакторскую проверку содержания и сверку оформления с выбранным СПС- либо ВИД/ФУНК-образцом. До утверждения работодателем документ обозначать как проект.

## 3. Ошибки, которые исключаем

- Не использовать ВИД-01 как шаблон должностной инструкции.
- Не объединять разные должности в одну инструкцию только из-за принадлежности к одному отделу.
- Не добавлять должности/операции, которых нет в согласованном перечне или в подтверждённых ответах.
- Не назначать СИЗ, группы по электробезопасности, обучение, возрастные/медицинские ограничения, периодичность инструктажей или нормы грузов без проверки нормативной и локальной основы.
- Не выдавать Markdown-черновик или автоматически созданный DOCX за готовый к печати документ.

## 4. Файлы, созданные до этого разбора

Первоначальные Markdown-заготовки и автоматически сгенерированные DOCX были подготовлены до разделения типов СПС/ВИД и без проверки по согласованным должностным образцам. В текущей рабочей версии они удалены/исключены из активной разработки. Их не использовать как готовый материал. Новая работа ведётся от анализа выше.
